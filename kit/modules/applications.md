# Module: applications
Folder: `10-applications/`

## Follow-up questions
- What they are applying to (universities, programmes, jobs, internships, scholarships), with deadlines.
- Status of each (researching, drafting, submitted, interview, decision).
- Documents they have ready (CV, transcripts, references, personal statement).

## Files
- `10-applications/tracker.md`: table of every application: name, deadline, requirements, status, link, next action. Verify every new deadline and requirement with a web search.
- `10-applications/materials.md`: CV versions, statements, referees and who has been asked.

## Index rows
| Applications tracker, statuses, deadlines | `10-applications/tracker.md` |
| CV, statements, referees | `10-applications/materials.md` |
